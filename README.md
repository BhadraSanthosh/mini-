# Mini Games

- **Word Guess**: daily 5-letter word puzzle with a shareable emoji result
- **Catch the Coin**: catch coins, dodge bombs, 30 seconds
- **Hangman**: guess the word before the bunny's 6 balloons pop
- **Tic Tac Toe**: Bunny vs Kitty, play the bot or a friend

No build step or dependencies. Open `index.html` in a browser to play locally.

## Share with friends (GitHub Pages)

1. Push this folder to a GitHub repo.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then save.
4. After a minute your game is live at `https://<your-username>.github.io/<repo-name>/`.

## Customize

Edit the `WORDS` list in `word-guess.html` to add your own words (5 letters, lowercase, space separated).
